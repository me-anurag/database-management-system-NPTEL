# Glossary of Key Terms

A running glossary of terms covered across the course. Add to this as you go through each week.

| Term | Short Definition | Introduced In |
|------|-------------------|----------------|
| RDBMS | Relational Database Management System, stores data in tables with relations | Week 1 |
| SQL | Structured Query Language, used to query and manipulate relational data | Week 2 |
| Relational Algebra | A formal set of operations used to query relational databases | Week 3 |
| ER Model | Entity-Relationship Model, used to design a database at a conceptual level | Week 3 |
| Normalization | Process of organizing data to reduce redundancy | Week 4 |
| Schema | The structure that defines how data is organized in a database | Week 4 |
| File Structure | The way records are physically stored on disk | Week 5 |
| Indexing | Data structure technique to speed up data retrieval | Week 6 |
| Hashing | Technique to map data to fixed-size values for fast lookup | Week 6 |
| Query Processing | Steps involved in translating a query into an execution plan | Week 6, Week 7 |
| Query Optimization | Process of choosing the most efficient way to execute a query | Week 7 |
| Transaction | A sequence of operations performed as a single logical unit of work | Week 7 |
| Serializability | Property ensuring concurrent transactions produce a consistent result | Week 7 |
| Concurrency Control | Techniques to manage simultaneous operations without conflicts | Week 8 |
| Recovery System | Mechanism to restore a database to a consistent state after a failure | Week 8 |

Keep updating this table as new terms come up week by week.
